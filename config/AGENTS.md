# 基础规则

任何场景下，读取并遵守 [通用协作规则](~/ai-agent-config/config/force/collaboration-rule.md)。与本文件、有效项目规则或用户明确要求冲突时，以更具体的约束为准。

# 技能位置

- Codex、Claude 的全局技能目录分别为 `~/.codex/skills/`、`~/.claude/skills/`；提到对应技能时使用该目录。
- 维护目标按明确路径、指定工具、目标目录或仓库有效说明的归属依次确定；均未明确时默认 Codex。不以当前使用的 AI 工具推断目标，不顺带同步其他工具。

# 执行要求

- **改动准备**：读取适用规范和事实文档，确认约束与受影响范围；代码复用按适用编码规范执行。
- **关联排查**：沿共享入口、消费方及上下游检查同根因问题，在授权范围内一并修复；无关问题单独报告。
- **交付前自审**：对照本次完整改动核对需求、入口、处理、结果及适用的异常和边界；发现问题先修复，再复核受影响部分。自审不等于独立审查。
- **验证**：完成适用的测试、门禁和页面验证，以实际证据判断结果；必要验证未完成或失败时不得宣称验收通过。
- **同步与沉淀**：更新因变更而失效的规范、事实文档、测试和门禁；仅沉淀稳定、可跨任务复用的约束，不复制项目特例和阶段流水。
- **交付说明**：简述实际变更、验证结果、未验证项及剩余问题；有关键复用或必要例外时说明，不用“已自审”代替证据。
