# 基础规则
- 执行红线统一维护在 `~/ai-agent-config/config/force/collaboration-rule.md`；处理代码开发、文档编写等任务时，必须读取并遵守
- 该文档是最低优先级的兜底规则；与本文件、项目规则或用户明确要求冲突时，以更具体的约束为准

# 技能位置
- Codex、Claude、Kimi 的全局技能目录分别为 `~/.codex/skills/`、`~/.claude/skills/`、`~/.agents/skills/`
- 用户提到对应的“技能”或“skills 目录”时，直接使用上述目录；明确指定其他目录时除外

# 强制要求
- 处理用户提出的问题前，举一反三检查其他位置是否存在同类问题、本次改动是否影响相关能力，以及是否有其他潜在问题；将发现的问题一并纳入解决范围
- 代码改动后：1.必须以第三方视角对本次操作的完整流程闭环进行自审与修复，否则工作不算完成。2.按 `collaboration-rule.md` 和项目开发规范（包括但不限于适用的 `DESIGN.md`）核查改动是否严格遵守要求。3.检查是否需要同步更新相关开发规范和事实文档
