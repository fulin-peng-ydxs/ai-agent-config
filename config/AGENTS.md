# 强制要求

- **实施改动前**：读取适用规范和事实文档，检索同类实现，确认共享入口、约束与受影响范围；不得照搬已有违规实现。
- **关联排查**：沿共享入口、消费方及上下游检查同根因问题，在已授权范围内一并修复；无关问题单独报告，不擅自扩大任务。
- **交付前自审**：基于本次完整改动，以审查者视角核对需求、入口、处理、结果及适用的异常和边界；发现问题先修复，再复核受影响部分。自审不等于独立第三方审查。
- **合规与验证**：按 collaboration-rule.md 和适用的项目规范完成复用、测试、门禁及页面验证；以实际执行证据判断结果，必要验证未完成或失败时不得宣称验收通过。
- **同步与沉淀**：同步更新因本次变更而失效的规范、事实文档、测试和门禁。仅将稳定、可跨任务复用的约束沉淀至全局规范或技能，不复制项目特例和阶段流水。
- **交付说明**：简要说明修复结果、关键复用入口或必要例外、实际验证结果，以及未验证项和剩余问题；不得用“已自审”代替证据。
