# 前端验证规范

通用要求遵循 [测试规范](../testing-standards.md)；本文补充页面呈现、交互及终端证据的专项差异。

## 范围与能力

- 按实际目标视口、输入方式和平台选场景。触摸、软键盘、安装态、Service Worker 和离线能力仅在项目使用且本次受影响时检查。
- 响应式或可安装不等于移动目标，窄视口不等于真实设备；范围不明时说明假设，不将未声明的移动支持设为阻塞。

## 验证方式与执行条件

- 呈现或操作可达性变化须实测受影响页面；Web 使用浏览器，原生交互使用能覆盖该行为的终端环境。
- 临时浏览、点击和截图优先使用内置浏览器；未经用户明确要求，不连接个人 Chrome、Edge 等外部浏览器。
- 入口生成、懒加载分包或资源路径受影响时，从构建产物核对相应入口、分包及资源加载。

## 按改动风险确定验证覆盖

| 改动涉及 | 关键动作与可观察结果 |
| --- | --- |
| 尺寸、空间、文案、列布局 | 在目标视口放入短长内容及极值，调整可用空间；按页面用途核对边界、换行、溢出和滚动范围，关键内容与操作按契约可见、可达 |
| 滚动、定位、弹层 | 滚动到相关区域与末端，展开、关闭并重新打开弹层；核对定位、遮挡、滚动归属及退出后恢复，按支持的关闭方式检查焦点与背景滚动恢复 |
| 显隐、异步、反馈 | 触发相关加载、空、成功、失败与重试；核对提示、内容和布局转换，重试后旧错误与加载态按结果更新，恢复后操作可继续 |
| 主题与交互样式 | 在受影响主题下触发支持的悬停、聚焦、选中和禁用状态；核对计算样式、实际渲染与可操作状态，状态退出后样式恢复 |
| 输入、焦点与控件语义 | 点击或用键盘进入、切换、取消并重新进入控件，涉及时展开与收起软键盘；核对命中、焦点顺序与恢复、输入值和可见区域，语义属性变化时核对可访问名称、角色与状态 |
| 表单、校验与提交 | 输入有效与无效值，提交、修正、重试及重复点击；核对错误定位、输入保留、提交中状态、请求次数和完成后的页面结果 |
| 列表、筛选与分页 | 切换筛选、排序和页码，控制慢请求与返回顺序；核对查询参数、当前页、空结果及选中项，旧结果不覆盖当前条件的数据 |
| 路由与缓存页面 | 直接进入、刷新、离开或隐藏、返回后再操作并等待延迟结果；核对路径参数、条件、草稿、滚动位置与浮层按契约保留或清理，过期结果不覆盖当前页面状态 |
| 安装态、离线或缓存更新 | 按影响验证安装启动、断网后操作、联网恢复及资源更新；核对安装入口、离线反馈、恢复后的数据及更新生效时点 |
| 共享组件和全局样式 | 选取容器、主题、状态及局部覆盖有差异的实际消费者，执行受影响操作；核对各使用点的呈现与反馈符合各自契约 |

## 证据能支持的结论

| 证据 | 证明范围 |
| --- | --- |
| 规范、源码和定向测试 | 契约、实现及相应逻辑；不证明实际外观或原生交互 |
| DOM、状态读取或脚本派发事件 | 对应状态与处理逻辑；不单独证明真实命中、指针捕获、触摸取消、惯性、原生焦点或软键盘往返 |
| 计算样式、几何和截图 | 当前版本、视口、主题及状态的呈现；不证明未操作的转换 |
| 实际点击、输入、滚动和切换 | 已执行交互及其反馈；按输入方式与终端区分证明范围 |

- 核对页面实际加载的脚本与样式；涉及 PWA 时同时检查 Service Worker 与缓存命中。
- 呈现比较注明版本；除明确比较的变量外，对齐视口、主题、内容和状态，并记录条件差异。样式文本、共享 class 和类型检查不能代替呈现证据。
- 区分桌面模拟、原生模拟器、设备、镜像和安装版；焦点或镜像输入工具栏不等于完整软键盘，桌面手机尺寸不证明原生触摸行为。平台限制须有目标版本的官方资料或实测依据。
