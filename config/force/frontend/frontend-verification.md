# 前端验证规范

维护前端验证方式、执行条件、页面场景及交互与终端证据要求；通用验证分类、通过判据及结果记录遵循 [测试规范](../testing-standards.md)。

## 范围与能力

- 继承指定页面、当前改动及消费者范围；独立全局审核无范围线索时采用审核技能的默认范围。
- 按实际目标视口、输入方式和平台选场景。触摸、软键盘、安装态、Service Worker 和离线能力仅在项目使用且本次受影响时检查。
- 响应式或可安装不等于移动目标，窄视口不等于真实设备；范围不明时说明假设，不将未声明的移动支持设为阻塞。
- 不因共享文件变化默认全站回归。

## 验证方式与执行条件

- 不影响布局与行为的文案、注释和展示属性做差异与格式检查；纯函数、状态计算、接口和领域规则做定向测试。
- 呈现或操作可达性变化必须完成受影响页面的浏览器实测；无法实测时说明缺口，不宣称页面验收通过。
- 临时浏览、点击和截图优先使用内置浏览器；未经用户明确要求，不连接个人 Chrome、Edge 等外部浏览器。
- 长期 E2E 用于低层测试不能覆盖、稳定且高价值的关键链路，不因局部改动默认新增。
- 构建配置、依赖、路由、懒加载、全局资源或发布产物受影响，或用户、项目要求时才完整构建。

## 按改动风险确定验证覆盖

依据用户要求、项目契约和专项判据，选择与本次影响有因果关系的场景；项目明确要求的覆盖不得遗漏，影响验收的覆盖取舍须说明依据。

| 改动涉及 | 场景与证据 |
| --- | --- |
| 尺寸、空间、文案、列布局 | 空间充足与受限、短长内容及极值；实际边界、换行、溢出和滚动范围 |
| 滚动、定位、弹层 | 滚动前后、展开关闭与恢复；所属区域、末端操作和退出结果 |
| 显隐、异步、反馈 | 相关加载、空、成功、失败及重试；转换前后的内容、几何变化和恢复结果 |
| 主题与交互样式 | 受影响主题及默认、悬停、聚焦、选中、禁用等状态；计算样式和渲染结果 |
| 输入与焦点 | 进入、切换、取消和恢复，涉及时含软键盘展开与收起；实际命中、焦点、输入值及可见区域 |
| 路由与缓存页面 | 首次进入、离开或隐藏、返回后再次操作和延迟结果；条件、草稿、位置及浮层状态 |
| 共享组件和全局样式 | 追踪真实消费者与局部覆盖，选择容器、主题、状态有差异的使用点 |

不穷举无关组合。已有缺陷先复现，再检查根因相关边界；留白、覆盖或位置变化是否有问题，须依据页面用途及契约判断。

## 证据能支持的结论

| 证据 | 证明范围 |
| --- | --- |
| 规范、源码和定向测试 | 契约、实现及相应逻辑；不证明实际外观或原生交互 |
| DOM、状态读取和脚本事件 | 对应状态与处理逻辑；不证明真实命中、指针捕获、触摸取消、惯性、原生焦点或软键盘往返 |
| 计算样式、几何和截图 | 当前版本、视口、主题及状态的呈现；不证明未操作的转换 |
| 实际点击、输入、滚动和切换 | 已触发并观察的交互；不外推到未覆盖的平台或状态，也不能替代业务计算、权限和数据一致性的服务或接口测试 |

- 确认页面实际加载最终源码对应版本；源码更新或服务启动不足以证明切换，PWA 同时检查页面资源与 SW/缓存。
- 比较时对齐版本、视口、主题、内容和状态；样式文本、共享 class 和类型检查不能代替呈现证据。
- 区分桌面模拟、原生模拟器、设备、镜像和安装版；焦点或镜像输入工具栏不等于完整软键盘，桌面手机尺寸不证明原生触摸行为。平台限制须有目标版本的官方资料或实测依据。
- 工具成功不等于交互发生。无变化时检查窗口、焦点和通道，纠正仍无效则停止重复操作并说明缺口，不猜测原因。

## 共享消费者与结论

- 一个默认使用点通过不能覆盖有差异的消费者；分别说明规则、源码及实际页面的检查结果。

## 多维审核协作

- 多技能共用范围内的调研与有效证据，只补新增风险或覆盖缺口，不因切换技能重复测试和截图；开发自审不自动产生专项审核或独立报告。
- 按判据区分体验、设计合规、复用和业务问题，同根因同修复点合并，保留各维度结论。
- 定级遵循专项标准，体验通过不能抵消契约或复用问题。
- 审核只输出结论；获修复授权后修改并复测，不擅改规范迁就实现。
